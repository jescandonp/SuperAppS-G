# sg-superapp-api

Backend base de I1 para la S&G Super App.

## Alcance actual

- API minima para login local, perfil actual, modulos y notificaciones shell.
- Modelos base de identidad y acceso alineados con `db/`.
- Configuracion de entorno para PostgreSQL y sesiones.

## Estado

El scaffold se deja versionado aunque el SDK `.NET` no este disponible en este ambiente. La compilacion y ejecucion quedan bloqueadas hasta instalar/confirmar la herramienta `dotnet`.
